# neon

Modern Qt6 GUI for the neo unified package manager on Gentoo Linux.

## Features
- Interactive Sidebar for selecting package backends (:ebuild, :flatp, :brew, :cask, :ebins)
- Real-time installed package count indicators per backend
- Search bar with backend dropdown filter
- Responsive asynchronous package operations powered by QThread
- Integrated ANSI-capable terminal output panel for real-time emerge/flatpak/brew logs
- Dark theme tailored for modern Linux desktops
